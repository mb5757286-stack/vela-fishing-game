# Рыбалка для Redmi Watch 5

Игра для Xiaomi Vela (быстрое приложение, `.rpk`). Управление — вращением коронки.

## Как играть

1. **Дальность.** Крути коронку — выбираешь, как далеко забросить. Чем дальше, тем крупнее рыба (и сом с щукой), но ждать дольше. Тап — заброс.
2. **Ожидание.** Не дёргай раньше времени: рано подсёк — рыба ушла.
3. **Поклёвка.** Часы вибрируют, поплавок дёргается. Подсекай: тап или резкий поворот коронки. На это 1,4 секунды.
4. **Вываживание.** Крути коронку, чтобы зелёная зона держала рыбу. Шкала справа (жёлтая) растёт, пока рыба в зоне, и падает, когда она вне зоны. Заполнил — поймал. Опустела — сорвалась.
5. Очки, рекордная рыба и счётчики сохраняются.

Зелёная точка в углу — индикатор: загорается, когда игра заметила вращение коронки.
Если она не загорается, а палец работает (проведи по экрану вверх-вниз вместо коронки), значит система не отдаёт коронку приложению, см. ниже.

## Сборка

Проект в формате AIoT-IDE (папка `src/`).

1. Открой папку `fishing` в AIoT-IDE.
2. Установи зависимости (`npm i`), нажми «Упаковать» — в `dist/` появится `.rpk`.
3. Установи на часы так же, как DJ Pads (Mi Fitness → Debug → сторонние приложения, пакет `com.mxga.fishing`).

Из консоли: `npm i && npx aiot build`.

## Сборка на GitHub

В репозитории есть workflow `.github/workflows/build.yml`: при каждом пуше он гоняет тест логики и собирает `.rpk`.
Готовый файл лежит во вкладке Actions → запуск → Artifacts → `fishing-rpk`.
Чтобы получить релиз с файлом, создай тег: `git tag v1.0.0 && git push --tags`.

## Настройка

- `src/pages/index/index.ux` → `CROWN_SENSITIVITY` — общая чувствительность коронки.
- `src/common/game.js` → `GAIN` (чувствительность в бою), `POWER_GAIN` (выбор дальности), `BITE_WINDOW`, таблица `FISH` (рыбы, скорость, размер зоны, шансы).

## Проверка баланса без часов

`npm test` (или `node test/sim.js`) прогоняет тысячи симулированных рыбалок разными «игроками».
