# Рыбалка для Redmi Watch 5

Игра для Xiaomi Vela (быстрое приложение `.rpk`). Управление — коронка, тапы и свайпы.

## Управление

| Жест | Где | Что делает |
|---|---|---|
| Коронка | Ловля, простой | выбор дальности заброса |
| Тап | Ловля | заброс, подсечка, дальше после улова |
| Коронка | Ловля, поклёвка | подсечка (быстрый поворот) |
| Коронка | Ловля, бой | двигает зелёную зону |
| Долгое нажатие | Бой | отпустить рыбу |
| Свайп ← / → | Простой или итог | переключить экран: Ловля → Магазин → Места |
| Коронка | Магазин, Места | выбрать строку |
| Тап | Магазин | купить или надеть вещь |
| Тап | Места | купить или перейти на место |

Свайп не работает во время заброса и боя, чтобы не уйти с экрана посреди рыбалки.
Вертикальные свайпы не используются: прокручиваемый слой под коронку их перехватывает.

## Игра

- **Места:** Пруд (бесплатно), Река (150), Озеро (400), Море (1000). У каждого места свой набор рыб и свой фон.
- **Снаряжение:** удочки (дальность и предел лески), катушки (сила зоны и выматывание), наживка (какие рыбы клюют лучше).
- **Тяжёлая рыба на слабой леске** выматывает вдвое быстрее. Щуку на бамбуковой удочке почти не вытащить.
- **Монеты** — за улов, по весу и виду рыбы. Сохраняются на часах.

## Картинки

Спрайты рыб и фоны лежат в `src/common/img/`. Они нарисованы скриптом `tools/make_art.py`:

```
python3 tools/make_art.py
```

Своя картинка? Замените PNG с тем же именем (`fish_<id>.png`, `bg_<место>.png`), скрипт перезапускать не нужно.

## Сборка на GitHub

`.github/workflows/build.yml` при каждом пуше собирает `.rpk`. Файл лежит во вкладке Actions → запуск → Artifacts → `fishing-rpk`. Для релиза создайте тег: `git tag v1.0.0 && git push --tags`.

## Сборка вручную

Открой папку в AIoT-IDE, нажми «Упаковать» (или `npm i && npx aiot build`). Установка на часы: Mi Fitness → Debug → сторонние приложения, пакет `com.mxga.fishing`.

## Проверка логики без часов

`node test/sim.js` прогоняет ботов по всем местам и проверяет магазин, сохранение и механику.

## Настройка

- `src/index/index.ux` → `CROWN_SENSITIVITY`, `MENU_STEP` — чувствительность коронки и меню.
- `src/common/game.js` → таблицы `FISH`, `LOCATIONS`, `RODS`, `REELS`, `BAITS`; `GAIN`, `COIN_RATE`, `BITE_WINDOW`.

## Что добавлено

- **Вибрация**: включается и выключается в настройках.
- **Редкие рыбы**: золотой карп (озёра, пруд) и белуга (море). Бьются рывками, платят в разы больше обычных.
- **Серия**: поимки подряд повышают бонус к монетам (до ×2).
- **Коллекция**: счётчик пойманных видов на экране мест.
- **Новые места**: зимнее озеро (лёд) и горный ручей. Новые текстуры в `src/common/img/bg_*.png`.
- **Жесты**: двойной тап в простое — заброс на полную дальность.



Датчики движения (`system.sensor`) официально не поддерживаются на Redmi Watch 5. Если датчик недоступен, движение отключается и остаётся коронка с тапами.
