# Утиные гонки

Vela-приложение для Redmi Watch 5 (Xiaomi Vela JS). Тренируете утку и бежите забеги.

## Управление

- **Экран ДОМ, тап** — тренировка (по очереди: скорость, сила, выносливость).
- **Тренировка:** коронкой держите жёлтую стрелку в зелёной зоне — она сама сдвигается. Чем точнее, тем больше прирост характеристики.
- **Экран ТРАССЫ, тап по трассе** — купить или побежать.
- **Забег:** тап — рывок вперёд. Частые рывки (чаще раз в 0.6с) почти не дают эффекта и быстро расходуют выносливость — рывки нужно делать точно, а не спамить.
- **‹ › внизу** — переключение экранов (ДОМ, УТКИ, ВЕЩИ, ТРАССЫ).
- **▲ ВЫБРАТЬ ▼** — навигация и покупка/выбор в меню.

## Экономика

- Монеты начисляются за забег, больше всего за 1-е место.
- В «УТКАХ» — покупка уток с более высоким потолком характеристик.
- В «ВЕЩАХ» — аксессуары с постоянным бонусом к одной характеристике.
- В «ТРАССАХ» — открытие новых, более сложных трасс с более быстрыми соперниками.

## Разработка

- Логика в `src/common/game.js`, проверяется в Node: `node test/sim.js`.
- Временные спрайты (пока нет своих): `python3 tools/make_art.py`, нужен Pillow.
- Сборка: `npx aiot build` (или через GitHub Actions `.github/workflows/build-ducks.yml`).

## Известные ограничения

- Не проверено на реальных часах — только симуляцией логики и сборкой CI.
- Спрайты уток и фоны — временные заглушки, нарисованные скриптом. Ждут замены на присланные.
